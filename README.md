## SeedanceCheap: prompts, examples and a 30-second video API

**[SeedanceCheap.com — try your first scene free if eligible](https://seedancecheap.com/?utm_source=github&utm_medium=profile&utm_campaign=developer_discovery)**

SeedanceCheap is an independent platform for 30-second Seedance 2.5 video requests. One video is $2.50; the 20-video pack is $30 ($1.50 each). One-time payment by card or crypto, with no subscription. Check current availability and sizes in the studio before submitting.

### Free tools and public examples

- [Character prompt builder](https://seedancecheap.com/characters?utm_source=github&utm_medium=profile&utm_campaign=developer_discovery): plan and reuse a text character sheet. Video generation is separate; text cannot guarantee the same face.
- [Video cookbook](https://pesoszpesosz.github.io/seedancecheap-video-cookbook/): scene planning, continuity exercises and generation-budget tools.
- [YouTube examples](https://www.youtube.com/@SeedanceCheap): complete outputs and the daily edited scene series.

### Build with the API

[API documentation](https://seedancecheap.com/api?utm_source=github&utm_medium=profile&utm_campaign=developer_discovery) · [Request builder](https://pesoszpesosz.github.io/seedancecheap-video-cookbook/api-request.html) · [Cookbook source](https://github.com/pesoszpesosz/seedancecheap-video-cookbook)

Save a unique request ID and the exact payload before submission so a lost response can be reconciled without creating another job. Never put API keys in public posts or repositories.

Face/person image references and input video are unsupported. Generation can take 10–50 minutes or longer; results vary. Delivered MP4s are private, with 24-hour downloads.
